## Deliberate launch gates

The code does not invent financial values. Before public launch, an authorized administrator must approve and fill in: budget, minor-unit value per P/R credit, bank replenishment cadence, default R-credit issuance policy, exchange min/max, payout/reconciliation adapter, and whether employees see fulfillment status. These are now governed settings rather than hard-coded or untracked TBDs.

The current build is therefore feature-complete for the configurable off-chain workflow, while the external cash/payroll/gift-card settlement itself remains an integration boundary rather than a fabricated “success” state.
