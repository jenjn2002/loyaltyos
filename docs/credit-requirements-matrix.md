## Deliberate launch gates

The code does not invent financial values. Before public launch, an authorized administrator must approve and fill in: budget, minor-unit value per P/R credit, bank replenishment cadence, default R-credit issuance policy, exchange min/max, accounting operating procedure, and whether employees see fulfillment status. These are now governed settings rather than hard-coded or untracked TBDs.

Rows 3–160 were reviewed individually; grouped ranges above only avoid repeating requirements that describe the same flow. “Done” does not claim that a real payout, production migration or employee trial has occurred.
